# Política de Privacidad — CreatorOps Hub

**Última actualización:** 18 de noviembre de 2026  
**Proyecto:** CreatorOps Hub  
**Repositorio Oficial:** [https://github.com/DevRousez/CreatorOpsHub](https://github.com/DevRousez/CreatorOpsHub)

En **CreatorOps Hub**, respetamos y protegemos la privacidad de los datos de nuestros usuarios. Esta política describe cómo se recopila, utiliza y protege la información al interactuar con nuestra aplicación y las APIs conectadas.

---

### 1. Datos que Recopilamos
CreatorOps Hub únicamente procesa los datos estrictamente necesarios para ofrecer el panel de estadísticas y analítica multicuenta:
- **Datos de Cuenta Pública y Métricas:** Nombres de usuario, identificadores de canal, conteo de seguidores/suscriptores, reproducciones de videos y métricas de interacción proporcionadas por las APIs oficiales (YouTube Data API v3 y TikTok Display API / Research API).
- **Credenciales y Tokens Locales:** Claves de API (`API Keys`, `Client Key`, `Client Secret`, `Access Tokens`) configuradas por el usuario para consultar sus propias estadísticas.

### 2. Cómo Usamos tus Datos
- Calcular resúmenes y comparativas de crecimiento de audiencia en las últimas 24 horas y los últimos 14 días.
- Mostrar gráficas de rendimiento visual dentro del panel privado del usuario.
- **No vendemos, no transferimos ni compartimos** tus datos, credenciales ni métricas analíticas con ninguna empresa tercera de publicidad o intermediarios de datos.

### 3. Almacenamiento y Seguridad
- Toda la configuración de claves y métricas se almacena en la infraestructura privada configurada por el usuario (base de datos Supabase del usuario y archivos locales cifrados/protegidos).
- Las conexiones con las APIs de TikTok y YouTube se realizan de forma segura mediante protocolos cifrados HTTPS / SSL.

### 4. Permisos de TikTok y Revocación
Cuando conectas tu cuenta de TikTok a CreatorOps Hub:
- Solo solicitamos los permisos de lectura básicos de perfil y estadísticas de video (`user.info.basic`, `video.list`).
- Puedes revocar el acceso a CreatorOps Hub en cualquier momento desde la configuración de seguridad y aplicaciones vinculadas en tu aplicación o cuenta de TikTok.

### 5. Eliminación de Datos
El usuario puede desconectar sus cuentas o eliminar todas las configuraciones y tokens en cualquier momento desde el panel de control (*Configuración > Desconectar cuenta*) o solicitándolo a través de nuestro canal de soporte.
