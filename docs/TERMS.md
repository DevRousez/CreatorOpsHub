# Términos de Servicio — CreatorOps Hub

**Última actualización:** 18 de noviembre de 2026  
**Proyecto:** CreatorOps Hub (Panel de Analítica y Operaciones Multicuenta)  
**Repositorio Oficial:** [https://github.com/DevRousez/CreatorOpsHub](https://github.com/DevRousez/CreatorOpsHub)

Bienvenido a **CreatorOps Hub**. Al utilizar nuestra plataforma, aplicación o servicios conectados, aceptas los siguientes términos y condiciones.

---

### 1. Descripción del Servicio
CreatorOps Hub es una herramienta de software diseñada para que creadores de contenido gestionen y analicen métricas de rendimiento de sus propios canales de video (YouTube, TikTok, etc.) de manera centralizada.

### 2. Uso Autorizado
- La aplicación está destinada exclusivamente a la consulta y monitoreo analítico de cuentas autorizadas por el usuario.
- El usuario es responsable de salvaguardar sus credenciales, claves de API y tokens de acceso.
- Queda prohibido el uso de la aplicación para actividades fraudulentas, spam, extracción no autorizada de datos masivos o cualquier actividad que infrinja las políticas de las plataformas integradas (TikTok Developer Terms, YouTube API Terms of Service).

### 3. Integración con Plataformas de Terceros
CreatorOps Hub se conecta a través de APIs oficiales:
- **TikTok for Developers:** Consulta estadísticas agregadas de perfil y métricas de videos con el consentimiento del usuario mediante OAuth2 y claves de desarrollador.
- **Google YouTube Data API:** Consulta datos analíticos públicos y del canal autenticado.

El uso de estas integraciones está sujeto a los términos y condiciones de cada plataforma respectiva.

### 4. Propiedad Intelectual
Todo el código, diseño, logotipos y arquitectura de CreatorOps Hub pertenecen a sus respectivos autores. El contenido audiovisual y las estadísticas analizadas son propiedad exclusiva de sus respectivos creadores.

### 5. Limitación de Responsabilidad
CreatorOps Hub se proporciona "tal cual" (*as is*), sin garantías expresas o implícitas sobre la disponibilidad continua de las APIs de terceros, cambios en sus políticas de cuota o cuellos de botella de red externos.
